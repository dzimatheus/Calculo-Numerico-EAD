Os códigos que organizei nestas pastas do GitHub é uma versão feita totalmente no Scilab, onde garanti que a lógica segue exatamente o que foi pedido nos enunciados, já que no arquivo anterior a condição de parada estava sobre |f(x_k)| < e, somente.
